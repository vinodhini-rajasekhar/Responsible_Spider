Responsible Spider

An explainable AI web crawler that shows what it takes, what it refuses, and what tried to hijack it.

Vinodhini Rajasekhar Responsible AI · Final Project · Fall 2026
github.com/vinodhini-rajasekhar/Responsible_Spider

1Why this matters

Audience: auditors · developers · educators Domain: AI scrapers & web agents

AI systems learn from — and browse — the web using scrapers most people never see.

Responsible AI need: make crawler decisions transparent and auditable.
  • Consent: Did it respect AI opt-outs (robots.txt, noai, TDMRep, ai.txt)? EU AI Act Art. 53 expects providers to honour them.
  • Security: Hidden text can instruct an AI to lie or push links (indirect prompt injection).
  • Privacy: Personal data can be collected without anyone noticing.

Core gap: what a human sees on a page vs. what a machine reads in the HTML.

2What I built

A working tool where a spider crawls a website map and gives every page a plain-language decision receipt.

ConsentHonour robots.txt, AI-bot blocks, noai, TDMRep
PrivacyFind and redact emails, phones, cards
SecurityDetect hidden text + quarantine injections
ExplainShow evidence, compare agents, find the cause

Contribution: one explainable system that joins web consent and AI security — so non-experts can see why an AI crawler acted.

5Limitations & future work

  • Limitation: Hidden-text checks use static HTML/CSS, not a full browser — some real-site tricks can slip through.
  • Limitation: Pattern-based detection misses subtle wording and can flag articles about injection.
  • Future: Expo user study — do receipts help people predict and trust crawler decisions?
  • Future: Browser-based rendering and a full benchmark on a higher API tier.
